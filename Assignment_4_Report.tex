\section*{Part 1: Product Requirements Document}

\subsection*{1. Product Overview}
PromptCrafter is an AI-assisted web service designed to help users generate highly optimized, professional-grade prompts for Large Language Models like ChatGPT, Claude, and Gemini. It solves the blank canvas problem by providing a structured, intuitive interface where users can select frameworks, roles, and magic keywords without needing to memorize prompt engineering techniques.

\subsection*{2. Target Users}
\begin{itemize}[noitemsep]
    \item Students \& Academics: Needs help structuring essays, summarizing papers, or planning study schedules.
    \item Developers: Needs help debugging code, writing documentation, or understanding new frameworks.
    \item Marketers \& Creators: Needs engaging copy, content strategies, and SEO optimization.
    \item General Public: People who want to use AI effectively but don't know how to write good prompts.
\end{itemize}
Pain Points Addressed: Low quality AI responses due to vague instructions, lack of knowledge about prompt engineering, and the repetitive nature of typing out constraints.

\subsection*{3. Project Goals}
\begin{itemize}[noitemsep]
    \item Provide a 1-minute, zero-learning-curve prompt generation experience.
    \item Implement at least 4 proven prompt frameworks.
    \item Ensure the output is instantly usable via a 1-click copy feature.
    \item Maintain a visually pleasing, modern glassmorphism UI.
\end{itemize}

\subsection*{4. Core User Scenario}
\begin{enumerate}[noitemsep]
    \item A user wants to write a marketing email but doesn't know how to instruct the AI.
    \item The user opens PromptCrafter.
    \item They select the Deep Persona framework and choose the Digital Marketer role.
    \item They enter their task: Write a launch email for a new productivity app.
    \item They open Advanced Options and check the Virtual Tip and Reverse Questioning magic keywords.
    \item A perfectly structured markdown prompt is dynamically generated.
    \item The user clicks Copy and pastes it into ChatGPT.
    \item The user clicks Save to Library to reuse this setup later.
\end{enumerate}

\subsection*{5. Feature List}
\begin{itemize}[noitemsep]
    \item Framework Selection: Dropdown to select different prompt engineering structures.
    \item Dynamic Prompt Generator: Real-time text generation based on inputs.
    \item Advanced Options: Inputs for Context, Target Audience, and Constraints.
    \item Prompt Boosters: Checkboxes to inject proven prompt hacks.
    \item Clipboard Copy: 1-click copy functionality.
    \item My Library: Save and delete favorite prompts using Local Storage.
\end{itemize}

\subsection*{6. Page Structure}
The application is a Single Page Application divided into three logical sections:
\begin{enumerate}[noitemsep]
    \item Home Section: Landing area with a hero title, brief description, and a Start button.
    \item Builder Section: The core tool area containing dropdowns, inputs, advanced options toggle, and the real-time result preview.
    \item Library Section: A dashboard grid displaying previously saved prompts.
\end{enumerate}

\subsection*{7. Technical Requirements}
\begin{itemize}[noitemsep]
    \item Frontend: HTML5, Vanilla CSS3, Vanilla JavaScript. No frontend frameworks are used to keep it lightweight.
    \item Styling: CSS variables for theming, CSS Flexbox/Grid for layout, and backdrop-filter for glassmorphism.
    \item Storage: Browser localStorage API for the Library feature.
    \item Deployment: Vercel.
\end{itemize}

\subsection*{8. Design Requirements}
\begin{itemize}[noitemsep]
    \item Theme: Dark Mode by default.
    \item Aesthetics: Glassmorphism - semi-transparent panels with background blur over floating, animated gradient orbs.
    \item Typography: Outfit Google Font for a modern, geometric, and clean look.
    \item Interactions: Smooth CSS transitions for button hovers, section toggling, and expanding the advanced options panel.
\end{itemize}

\subsection*{9. Milestones}
\begin{enumerate}[noitemsep]
    \item Idea Definition \& PRD Completion: Outline the problem, solution, and core features.
    \item First Prototype: Implement the basic HTML/CSS skeleton and simple string-concatenation JS logic.
    \item Advanced Implementation: Integrate prompt frameworks and magic keywords based on prompt engineering research.
    \item Refinement \& Testing: Add smooth UI transitions and test Local Storage persistence.
    \item Final Deployment: Push code to GitHub and deploy publicly via Vercel.
\end{enumerate}

\section*{Part 2: AI-Assisted Development Report}

\subsection*{1. AI Tools Used}
\begin{itemize}[noitemsep]
    \item Gemini 3.1 Pro (via Antigravity IDE)
\end{itemize}

\subsection*{2. Tasks Assisted by AI}
\begin{itemize}[noitemsep]
    \item PRD Writing: The core idea for a prompt generator was developed independently. The AI was subsequently utilized to structure the concepts into a professional Product Requirements Document (PRD) meeting the assignment guidelines.
    \item UI/UX Design \& Publishing: The AI was instructed to assist in writing the HTML skeleton and applying modern CSS styling, including glassmorphism, dark mode, and background animations.
    \item JavaScript Implementation: The AI was utilized to help implement the core logic, such as real-time prompt assembly, clipboard copying, and saving data using the browser Local Storage.
    \item Prompt Engineering Logic: Prompt engineering techniques (such as Chain of Thought and reverse questioning) were researched, and the AI was instructed to implement these dynamic frameworks and magic keyword checkboxes.
\end{itemize}

\subsection*{3. Representative Prompts Used}
\begin{enumerate}[noitemsep]
    \item A custom AI prompt generator is proposed. Draft a professional PRD that includes the Product Overview, Target Users, and Feature List.
    \item Based on the drafted PRD, generate the index.html, style.css, and script.js files. Ensure the design utilizes a modern glassmorphism aesthetic and a dark theme.
    \item Based on prompt hacking techniques such as promising a tip and asking for reverse questions found in a research article, incorporate these as magic keyword checkboxes in the web application.
\end{enumerate}

\subsection*{4. Modifications and Improvements}
\begin{itemize}[noitemsep]
    \item Natural Prompt Generation: The initial string concatenation method suggested by the AI was too basic. The engine was completely overhauled to utilize a switch-case statement that handles 4 distinct frameworks (Basic, Chain of Thought, Persona, Extraction) and outputs structured markdown.
    \item Prompt Boosters: Based on independent research, logic and UI for toggleable advanced options were added. These magic keywords (e.g., promising a virtual tip, inducing reverse questions) are automatically appended to the bottom of the prompt when checked, significantly improving the output quality.
    \item Design Details: The initial background gradient animation was too fast and distracting. The CSS animation duration was adjusted to 10 seconds to create a much smoother and less intrusive visual experience, and smooth dropdown animations were added to the advanced options panel.
\end{itemize}

\subsection*{5. Bugs, Errors, and Limitations Found}
\begin{itemize}[noitemsep]
    \item Issue: When opening the browser to use the library (Local Storage) feature for the first time, the application threw a JavaScript error because the stored data was null, which broke the array forEach method.
    \item Solution: This was resolved by adding a logical OR operator when parsing the JSON data. If the data is empty or null, it now returns an empty array as the default value, successfully eliminating the error.
\end{itemize}
