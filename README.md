# PromptCrafter (AI Prompt Builder)

## Project Overview
PromptCrafter is a web service designed to help users generate high-quality, optimized prompts for AI tools like ChatGPT and Claude. By simply selecting a few options such as role, task, tone, and format, users can instantly craft the perfect prompt without needing extensive prompt engineering knowledge.

## Main Features
- **Prompt Frameworks:** Choose from structural templates like Basic (RTF), Chain of Thought, Deep Persona, and Information Extraction.
- **Advanced Options:** Fine-tune prompts by adding Background Context, Target Audience, Constraints, and Few-Shot Examples.
- **Prompt Boosters (Magic Keywords):** Instantly inject proven prompt engineering techniques (like offering a virtual tip or requesting reverse questions) with a single click.
- **Dynamic Prompt Generation:** Automatically assembles a high-quality, markdown-formatted prompt based on user-selected criteria in real-time.
- **My Library (Local Storage):** Save favorite prompts to the browser's local storage to use them again later.
- **Modern UI/UX:** Sleek glassmorphism design with smooth toggle animations for advanced options.

## How to Run Locally
Since this project is a static web page with no backend dependencies, running it locally is very simple:
1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser (e.g., Chrome, Edge, Safari).
3. No server, database, or build process is required!
